# 安全与合规

## 一、这个工具在做什么，不做什么

**做**：在本机按名字分配浏览器实例、维护独立的浏览器用户数据目录（登录态）、把调试端口告诉你、记录页面上发生的人机交互、出错时写一条告警。

**不做**：

- 不破解、不绕过任何访问控制：验证码、滑块、人机校验、IP 封禁、登录墙、付费墙
- 不伪造身份、不批量注册、不刷量、不虚假交易
- 不代理流量、不改请求、不注入伪造数据到目标站
- 不上传任何数据到作者或第三方服务器
- 不提供规避目标站反爬策略的手段（频率伪装、指纹伪装等的"教程"）

如果你的场景需要上述能力，本工具不合适。

## 二、攻击面与边界

| 面 | 现状 | 风险与建议 |
|---|---|---|
| 面板 HTTP | 监听 `127.0.0.1:9410` | 同机任意程序可访问，无认证。多用户机器请改端口或只在自己账户下跑 |

**CSRF 提醒（重要）**：面板只监听 `127.0.0.1`，但它**不校验 Origin/Referer**——你在同一个浏览器里打开的**任何网页**，都可以通过 JS 向 `http://127.0.0.1:9410/api/farm?...` 发请求，从而驱动你已登录的实例跳转、或用 `act=show` 把窗口弹出来。使用建议：① 面板开着的时候，别在同一个浏览器里逛不受信任的站点；② 把面板端口用本机防火墙限制在回环；③ 需要更强隔离时，改 `farm.json` 的 `panelPort` 换随机端口并只在自己知道的情况下使用。这一条已知、未修，按"现状提供"发布。
| CDP 调试端口 | 每个实例 `127.0.0.1:<port>` | 拿到端口即可完全控制该浏览器（读 cookie、执行脚本）。端口不要外泄、不要做端口转发 |
| 浏览器进程 | 以当前用户身份运行 | 权限等同你本人。不要用它访问你不敢用主浏览器访问的站点 |
| 数据目录 | `%USERPROFILE%\AgentBrowser` | 含登录 cookie，等同凭据。注意本机磁盘加密与备份策略 |
| 日志 | `logs\activity.jsonl` | 会记录输入内容（可能含账号、金额）。分享日志前先检查、脱敏 |
| 告警队列 | `logs\alerts.jsonl` | 同上；推送到聊天工具前先确认内容 |

**建议**：

1. 只在单人使用、可信的机器上跑
2. 不要把 9410 或调试端口映射到公网 / 局域网
3. 定期 `farm close` + 清理 profile
4. 分享日志、截图、配置前先脱敏（实例名、账号、URL、金额）

## 三、合规使用自查清单

使用前请逐条确认：

- [ ] 我访问的系统是我有权访问的（自有账号、已获授权、公开可访问）
- [ ] 我的操作符合目标网站的服务条款与使用政策
- [ ] 我的采集/操作频率不构成对目标服务的异常负载
- [ ] 我处理的数据不违反个人信息保护、数据安全、商业秘密相关法律
- [ ] 我不会用自动化替代需要人工确认的授权行为（转账、支付、签约等）
- [ ] 我了解并接受：账号被限制、被封禁、数据丢失等后果由我自己承担

## 四、数据留存

- 全部数据在本机，随目录删除而消失
- 无遥测、无版本检查回传、无崩溃上报
- `activity.jsonl` 3MB 轮转，保留最近 2000 行；其余文件无自动清理，需要自己删

## 五、第三方组件

- 调用的浏览器（Chrome / Edge）由各自权利人提供，适用其许可与隐私政策
- 无其他运行时依赖（不需要 Node / Python / Docker / npm 包）
