# 命令手册

所有命令通过同一个脚本调用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File browser-pool.ps1 <命令> [参数]
```

退出码：`0` 成功；`2` 运行出错（浏览器起不来、CDP 连不上等）；`4` 参数错误 / 实例没在跑 / 入口表里没有该入口。

---

## 面板

面板窗口的自动打开规则：有头实例调用时，若面板页面已经开着（页面每 15 秒写一次心跳，40 秒内有效）就不再开第二个；没开着才自动打开。无头实例只确保面板服务在跑，不弹窗。

### panel [-Port 9410] [-Bg]

起本地网页面板。

- `-Port`：端口，默认 9410
- `-Bg`：后台跑并立即返回（常驻用这个）

```powershell
powershell -File browser-pool.ps1 panel -Bg
# [OK] 面板已启动：http://127.0.0.1:9410/
```

面板会做三件事：展示任务卡片与操作日志、每 3 秒 drain 一次浏览器埋点、显示后台入口表。

**注意**：`farm open` 会自动确保面板在跑（有浏览器活动就一定有面板），一般不需要手动起。

### stop

停掉后台面板（不影响正在跑的浏览器实例）。

```powershell
powershell -File browser-pool.ps1 stop
```

## 实例

### farm open \<名字> [网址]

起一个浏览器实例，或复用已在跑的同名实例。

- 名字：自定义，会用于 profile 目录名与日志里的实例标识
- 网址：可选，起完直接打开

```powershell
powershell -File browser-pool.ps1 farm open 报表后台 https://example.com/
```

输出里给出 `http://127.0.0.1:<端口>`，Agent 侧拿这个端口做 CDP 连接。

行为细节：

- 已有同名实例在跑 → 直接返回原端口（登录态复用）
- 实例登记过但进程已退 → 用原端口、原 profile 重新拉起（登录态还在）
- 超过实例数上限（默认 8）→ 报错，提示先 close 或改上限
- 自动开一个任务段（面板上一张卡）
- 自动确保面板在跑

### farm list

列全部实例。

```powershell
powershell -File browser-pool.ps1 farm list
```

输出：名字 / 端口 / 模式（有头/无头）/ 标签页数 / 内存 / 状态 / 最后使用。

### farm close \<名字>

关掉实例。**profile 和登录态保留**，下次 open 还是原来那个浏览器身份。

```powershell
powershell -File browser-pool.ps1 farm close 报表后台
```

### farm port \<名字\>

查这个实例的端口。**端口是名字派生的唯一映射**：MD5 前四字节 mod 40 → 9360-9399 段（避开其它工具常用的 9330-9339），同名跨机器、跨重装都是同一个端口；登记后终身绑定。撞车或端口被占会按序后探（实际端口记进 farm.json），所以 agent 拿端口以 `farm open` 输出或本命令为准。

```
powershell -File browser-pool.ps1 farm port 报表后台
#   [OK] 报表后台 端口 9371（=派生值，同名跨机器一致）
```

### farm scan

扫本机所有带调试端口的浏览器，只读，不改任何东西。三类标注：`已登记:<名字>` / `未登记·可收编` / `工具·不动`。

```
powershell -File browser-pool.ps1 farm scan
```

### farm adopt \<端口> [名字]

收编一个外部实例：抓它当前首页 → 关掉它 → 用池子的独立 profile **在同一个端口**重起（技能侧认的端口不变）→ 打开原来的首页。

```
powershell -File browser-pool.ps1 farm adopt 9222 我的号
```

代价说清楚：原 profile 里的登录态不会迁移过来，收编后要重新登录一次；之后登录态归池子管，长期有效。工具白名单里的端口（默认 9222、9223，可在 `farm.json` 的 `excludePorts` 改）会被拒绝，不会误杀 agent 自己的浏览器。

### farm watch on/off [端口名单]

后台收纳守护，每 3 秒扫一次本机带调试端口的浏览器。**默认强制开启**：任何 farm 命令都会自动确保守护在跑（这是 Agent 版的核心——不用记得开，它一直在）。

- `farm watch` / `farm watch on`：确认开启并拉起守护。按收纳模式处理外部浏览器（见下）。
- `farm watch 9333,9444`：把这些端口写进 `autoAdoptPorts` 强收编名单，这些端口一出现就整份收编（关掉、用池子 profile **同端口**重起，需重登一次）。
- `farm watch off`：关总开关并通知守护退出。之后的 farm 命令不会再拉起（要重新收纳用 `farm watch on`）。

**收纳模式三态**（`farm watch adopt see|strong|off`，老写法 on/off 仍认）：

- `see`（默认）：非白名单的外部浏览器纳管——登记进池子、保留原进程和登录态，立刻能 park / 关闭 / 看日志。
- `strong`：非白名单的外部浏览器出现就**强收编转正**——kill 自起 → 池子 profile **同端口**重起（技能侧端口无感）→ 带回首页。之后 `farm show` 扫码登录一次、`farm hide` 收回，登录态永久锁进池子。**给 Agent 专机用**；本机若有其它工具的长驻浏览器（带调试端口），先 `farm whitelist` 加白，否则会被收编（要重登）。
- `off`：守护只做回收+清理，不碰外部浏览器。

守护同时负责空闲回收（见 `farm recycle`），执行记录在 `logs\watch.log`。

### farm whitelist [端口,...]

白名单：这些端口的浏览器**不收纳、不收编**——自己日常用的调试浏览器放这里。默认 9222、9223。

```
powershell -File browser-pool.ps1 farm whitelist 9333,9444    # 设置
powershell -File browser-pool.ps1 farm whitelist              # 查看
powershell -File browser-pool.ps1 farm whitelist reset        # 回默认 9222,9223
```

正在跑的守护每轮都重新读白名单，改完 3 秒内生效，不用重启。

### farm recycle [实例分钟] [tab分钟]

空闲回收参数。默认实例 30 分钟、标签页 15 分钟。

- 判定「空闲」：距上次 `lastUsedAt`（每次 open/goto/tabnew/task 刷新）或最近一次页面操作事件的分钟数
- 三道保底不误杀：端口上有 CDP 客户端连接（任务正在驱动）不动；近期有操作不动；没时间戳可判不动
- 标签页层多一道闸门：实例整体近 tabIdleMin 分钟被动过就不清任何 tab（防刚开出来还没产生事件的页面被误收）
- 关实例只关进程，profile 和登录态永远保留；`farm open` 同名实例即复活
- 关标签页保底留 1 页；about:blank / 内置页不关
- **自动回收只管池子亲生的实例**；外部纳管的只看得见、能手动关，要纳入生命周期先 `farm adopt` 转正

```
powershell -File browser-pool.ps1 farm recycle 10 5    # 实例 10 分钟 / tab 5 分钟
powershell -File browser-pool.ps1 farm recycle off     # 全关
powershell -File browser-pool.ps1 farm recycle sweep   # 立即扫一轮（不等守护）
```

### farm forget \<名字>

从登记表里删掉（不动磁盘上的 profile 目录）。用于实例已删但登记还留着的清理。

### farm limits [上限]

查看或修改实例数上限（默认 8）。

```powershell
powershell -File browser-pool.ps1 farm limits        # 查看
powershell -File browser-pool.ps1 farm limits 20     # 改成 20
```

## 窗口形态

### farm show \<名字>

把窗口拉到前台（需要人操作时用，比如扫码登录）。

注意：如果实例当前是**无头**模式，`show` 会**关掉进程再以有头重启**——端口不变，**标签页会在重启后按序自动还原**（池子版修复：底版会全丢）。要扫码的典型用法：`farm show` → 扫码 → `farm hide` 收回后台。

### farm hide \<名字>

把窗口收起来。同理：如果实例当前是**有头**模式，`hide` 会**关掉进程再以无头重启**，端口不变、**标签页自动还原**。

### farm park \<名字>

把有头窗口挪到屏幕外（坐标 -3000,-3000）。**进程照跑、页面照常渲染，但不抢焦点**，适合"起一次登录后就让它自己在后台跑"的场景。

```powershell
powershell -File browser-pool.ps1 farm park 报表后台
```

无头实例调用立即返回成功。实例不存在返回 4。

## 标签页

### farm tabs \<名字>

列这个实例的所有标签页（序号 + 标题 + URL）。

### farm tabnew \<名字> \<网址>

在同一个实例里新开标签页。**同实例 = 同 profile = 不用重新登录。**

```powershell
powershell -File browser-pool.ps1 farm tabnew 报表后台 https://example.com/report
```

### farm tabclose \<名字> \<序号|all>

关标签页。序号来自 `farm tabs`。

**注意**：无头实例关掉最后一个标签页，整个进程会退出。任何关页逻辑请保底留 1 页。

## 后台入口表（可选）

把常用系统登记到 `webapps.json`，面板底部会列出，点一下就在对应实例里开标签页。

**文件要放在数据目录**（默认 `%USERPROFILE%\AgentBrowser`，设了 `AGENTBROWSER_HOME` 就用那个）：把包里的 `webapps.sample.json` 复制过去改名 `webapps.json`，再按注释填。留在包目录里改是不生效的。

### farm apps

列入口表 + 每个入口当前是否已打开。

### farm openapp \<后台名>

打开某个入口；对应实例没起会自动起。

`webapps.json` 格式（参考 `webapps.sample.json`）：

```json
{
  "apps": [
    { "app": "报表后台", "skill": "", "instance": "报表后台", "url": "https://example.com/" }
  ]
}
```

## 任务与告警

### farm task \<名字> [任务名]

开一个新任务段。之后这个实例上的浏览器操作都归这个任务，面板上一张卡。

```powershell
powershell -File browser-pool.ps1 farm task 报表后台 "月度取数"
```

不传任务名自动生成（实例名 + 时间）。不调用也能用：`farm open` 时自动开段，超过 30 分钟自动换新段。

**用途**：让面板把"一件事"的操作聚在一起，而不是一个大杂烩流水。

### farm alert \<名字> \<级别> <消息>

写一条告警到 `logs\alerts.jsonl`。两种写法等价：`farm alert <名字> <级别> <消息>` 或 `farm alert <名字> '<级别>|<消息>'`（级别 info / warn / error，缺省 info）。

- 级别：`info` / `warn` / `error`
- 消息：任意文本，建议一句话说清"谁、什么错、要人做什么"

```powershell
powershell -File browser-pool.ps1 farm alert 报表后台 warn "登录失效，需要扫码一次"
```

配合任意定时任务扫未推送告警即可实现主动通知。示例（每 15 分钟）：

```python
# 扫 alerts.jsonl 里 pushed=false 的条目，推送到你的通知渠道，然后标 pushed=true
```

告警写入失败不影响业务，但也不要吞掉——业务脚本里应该 try/catch 包住，日志里留痕。

## 环境变量

| 变量 | 作用 | 默认 |
|---|---|---|
| `BROWSER_POOL_HOME` | 数据目录（farm.json、profile、日志都在下面）；旧名 `AGENTBROWSER_HOME` 仍认 | `%USERPROFILE%\BrowserPool` |

测试或多环境隔离时改它，互不干扰：

```powershell
$env:AGENTBROWSER_HOME = "$env:TEMP\df-test"
```

## 常见失败

| 输出 | 原因 | 处理 |
|---|---|---|
| `没有这个实例：X（先 farm open）` | 名字打错或没起过 | 先 `farm open X` |
| `实例没在跑（先 farm open X）` | 登记在但进程退了 | `farm open X` 重新拉起（登录态还在） |
| `实例数已达上限 8` | 开的太多 | `farm close` 不用的，或 `farm limits 20` |
| `浏览器端口池 9330-9399 用完了` | 端口全占 | `farm list` 看谁在用，close 掉 |
| `面板启动后立刻退出` | 端口被占 / 看 `panel_auto.log` | `stop` 后重起，或 `-Port` 换端口 |
