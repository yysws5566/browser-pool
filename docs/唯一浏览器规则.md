# 唯一浏览器规则（可选，装进 Agent 常驻规则）

> 用途：让 Agent 每次做网页任务都先走 AgentBrowser 拿端口，而不是自己 `Start-Process chrome`。
> 装法：`powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1`

## 规则正文

- **唯一浏览器**：所有网页任务起浏览器必须走 BrowserPool 浏览器池 —— `browser-pool.ps1 farm open <实例> [网址]` 拿端口再连 CDP。**禁止自己 Start-Process chrome/edge、禁止自建 profile 和调试端口**。登录态与启动参数只有一份；起不来 / 登录失效走 `farm alert` 告警。要扫码登录时 `farm show <实例>` 切有头（标签页自动还原），登完 `farm hide <实例>` 收回后台。
- **不关别人的页面**：只操作自己开的实例与标签页；关页逻辑必须保底留 1 页（无头实例关掉最后一页会整进程退出）。
- **一个任务一个任务段**：开工前 `farm task <实例> <任务名>`，让面板把这件事的操作聚在一张卡上。

## 为什么值得装

| 不装的后果 | 装了之后 |
|---|---|
| 每个技能各扫一次码，登录态维护 N 份 | 一个实例一次登录，长期复用 |
| 启动参数散落各处，少一个就静默失败 | 参数只在 farm.json 一处定义 |
| 任务跑挂没人知道 | `farm alert` + 定时扫告警文件，主动通知 |
| Agent 说"做完了"但你看不见过程 | 面板一任务一卡，每步操作可回溯 |

## 优先级怎么写

放在 Agent 常驻规则（AGENTS.md 之类）的"硬约束"段，优先级高于普通偏好：

```
- 唯一浏览器：所有网页任务起浏览器必须走 AgentBrowser（farm open 拿端口），禁止自起 Chrome。
```

细则越短越容易被遵守；长文档放 `rules/` 下按需读。
